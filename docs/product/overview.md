# Product overview

Status: Accepted

Lukas is a personal finance PoC focused first on Chile. The product starts with
manual workflows, CSV/Excel imports and a local-first desktop experience, while
keeping room for Open Finance, public financial APIs and future web/SaaS hosts.

The initial product should prioritize trust over automation. Imported data must
be reviewable, corrections must be visible, and reports should explain whether
their numbers come from actual, pending, estimated, adjusted or reconciled data.

## Initial scope

- Manual transaction creation and editing.
- CSV and Excel imports mapped to explicit accounts.
- Review flows for duplicates, ambiguous rows and source corrections.
- Monthly budget and cashflow views.
- Goals, reserves and basic projection scenarios.
- Multicurrency accounts and transactions, with CLP as the first reporting base.
- Chile-first presentation rules for dates, money and local financial behavior.

## Deferred scope

- Real Open Finance provider integration.
- Splitwise, Fintual or other external API integrations.
- Public API and MCP access.
- Chile annual tax-preparation module.
- Hosted SaaS, cloud sync, billing and multi-tenant operations.
