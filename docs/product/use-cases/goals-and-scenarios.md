# Goals and scenarios

Status: Accepted

## UC-008: Create projection based on history

The user can project future cashflow from historical transactions, recurring
patterns and current balances. The result must show which assumptions were used.

## UC-009: Create projection with user estimates

The user can override or add assumptions such as expected income, expected
spending, one-off purchases, savings targets or debt payments.

User estimates must remain separate from actual ledger history.

## UC-015: Define financial goals

The user can create goals and reserves for future expenses, emergency funds,
debt repayment or planned purchases.

Goals and reserves are allocations of money, not hidden bank accounts or
unexplained ledger movements.

## UC-016: Plan scenarios

The user can compare alternative financial plans before acting on them.
Scenarios reuse real balances, goals, allocations and recurring transactions
without mutating real history.

## UC-017: Project negative or survival scenario

The user can model income loss, reduced spending, severance estimates,
liquidity, debt strategy, reserves and account exhaustion.

Survival scenarios should make assumptions explicit because their purpose is
planning under stress, not predicting a guaranteed outcome.
